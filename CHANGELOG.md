## [1.0.0] - 2026-10-11

### Added
- Complete channel scraper for YouTube `@learnwithashmeet` community posts.
- InnerTube browse continuation extraction engine.
- High-resolution card parameter conversion (`=s0` direct unscaled source image).
- Asynchronous downloader with connection pooling and semaphore concurrency limiting.
- Automated generation of `info.txt` metadata per post.
- Native Node.js `node:test` verification suite validating post structure, image URLs, and folder consistency.
- OpenSSF compliant governance and GitHub Actions CI ecosystem.
